# スタンプくんっ🤠 by nk2

SNSに写真を投稿するとき、顔を隠したい人のところへ絵文字スタンプを貼るためのシンプルなアプリです。
写真は端末の中だけで処理され、外部に送信されることはありません。

開く: https://b0544109-nk2.github.io/stamp-kun/

## 使い方

1. 「写真を選ぶ」から写真を開く
2. スタンプを選んで、隠したい顔に貼る
   - 自由に貼る：タップで配置、ドラッグ・ピンチ・矢印ボタンで調整
   - 四角で囲んで自動：顔を指で四角く囲むと、顔の大きさと傾きに合わせて自動で貼る
3. 「保存」で書き出し（解像度は元のまま）

絵文字は5つのスタイル（Twemoji／Noto／OpenMoji／Fluentカラー／Fluentフラット）から選べます。

## ホーム画面への追加（アプリとして使う）

### Android（Chrome）
1. Chrome でこのページを開く
2. 右上の「︙」メニューをタップ
3. 「アプリをインストール」（出ない場合は「ホーム画面に追加」）をタップ
4. 「インストール」を押すと、ホーム画面にアイコンができます

### iPhone（Safari）
1. **Safari** でこのページを開く（Chrome では追加できないので必ず Safari で）
2. 画面下の共有ボタン（四角から矢印が出ているアイコン）をタップ
3. 「ホーム画面に追加」をタップ
4. 名前を確認して「追加」を押すと、ホーム画面にアイコンができます
